Form rules
  1. Label above the input, never at the side. Inputs 40 px.
  2. Fields are in cards with a heading. Same cards and same order on both layouts.
  3. Desktop: max. 720 px wide, centered. Max. 2 columns, only for short fields.
  4. Footer bar at the bottom of the screen, always visible: Delete on the left (only in edit mode), Cancel + Save on the right. Save is always the last button.
  5. Errors: red border + text under the field. No pop-up.
  6. On/off values use a toggle, not a checkbox.

Detail-page rules
  1. Header: back arrow · title · status chip.
  2. Actions: desktop = text buttons in the header + ⋮. Phone = the same 2 main actions in the footer bar, the rest in ⋮ in the app bar. (Same place as Save/Cancel on forms.)
  3. Key-value data in a card: label (muted) on the left, value on the right, rows 40 px.
  4. Lists inside a detail page use the normal list component.
  5. Desktop: max. 2 columns. Phone: 1 column, same order.

Step-editor rules
  1. Every step = one 56 px row: drag handle (SVG) · number · type icon · title + one detail line · actions.
  2. Type icon with color tells the step type: blue = action, purple = loop, teal = if.
  3. Blocks: colored left border, child rows indented 28 px, “Add step to …” at the end of the block.
  4. Reorder: drag on both layouts; “Move up/down” in ⋮ as the keyboard/touch fallback. No ↑/↓ buttons in the row.
  5. Desktop: Edit + Duplicate + ⋮. Phone: only ⋮.
  6. Editing a step opens the normal form page (rule set A) — on phone a full page, on desktop a side panel of 480 px.

Big-list rules
  1. Same list component and 56 px rows. Expand chevron = icon button in a fixed 48 px first column.
  2. Expanded panel spans all columns and can be any height; the normal rows stay 56 px.
  3. Time uses a monospace font and a fixed 168 px column; sorting arrow is in the header.
  4. Filters are chips (on/off) on both layouts. On phone the filter icon opens all filters as a form page.
  5. Paging at the bottom (25 rows), no endless scroll, so the page does not jump.
  6. Phone row: name · status chip · time · type — tap expands.

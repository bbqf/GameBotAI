Rules (proposal 1)
  1. Page header: title on the left, max. one primary button on the right. Same on all pages and both layouts.
  2. Filter bar under the header, not inside table headers. Inputs are 40 px high.
  3. One list component. Desktop = table with table-layout: fixed; each column has a fixed px width, only "Name" stretches. Rows are always 56 px; text does not wrap, it gets "…". Phone = the same data as 64 px rows: name on line 1, status + one meta value on line 2.
  4. Row actions: icon buttons with a tooltip. Phone shows max. 1 main action + "⋮" menu. Desktop shows max. 3 + "⋮". Disabled actions stay in place (dimmed), so columns do not move. Delete is always in "⋮", red, and asks for confirmation.
  5. Navigation: same areas, same order, same icons. Bottom tab bar on phone, top tabs on desktop.
  6. Buttons: 4 text variants + 1 icon button. Text buttons for page and form actions; icon buttons only in rows and toolbars. Height 40 px (44 px touch area on phone).
  7. Status chip: one component, one color per state, fixed width.
  8. Detail pages: back-arrow icon + title, no "← Back" text.

Also: one SVG icon set for everything (no ⠿ ↑ ↓ ✕ text glyphs), colors and sizes only from theme tokens.

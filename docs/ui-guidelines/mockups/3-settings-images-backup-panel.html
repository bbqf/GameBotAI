Rules
  1. Two modes on one page = segmented control (not two separate pages, not tabs).
  2. Checkbox lists: 56 px rows, "Select all" as the first row with a count.

I. Step editor with the side panel (desktop)

The list stays visible; the selected step is marked. The panel uses the normal form rules and its own footer bar.

Rules
  1. Side panel: 480 px, on the right, full height under the tabs. Header = title + close (✕ as SVG icon).
  2. The edited row is marked: light blue background + 3 px blue left line.
  3. Panel content = form rules (labels above, cards, 40 px inputs). Its footer: Cancel + Apply.
  4. "Apply" changes the step in the list; "Save" in the page footer saves the sequence. The page footer shows "Changes are not saved".
  5. The same side panel is used for other "edit one item of a list" cases on desktop (for example a configuration parameter). On phone it is always a full page.
